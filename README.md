# Prakhar Singh — Animated Portfolio

A responsive, animated single-page developer portfolio built with plain HTML, CSS and JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser, or use VS Code Live Server.
3. Edit your content in `index.html`; customize colors and layout in `styles.css`.

## Included interactions
- Scroll-triggered reveal animations
- Floating hero artwork and animated project illustrations
- Cursor-following ambient glow on desktop
- Magnetic primary CTA
- Responsive mobile navigation
- Hover effects and reduced-motion accessibility support

## Before publishing
- Confirm the contact details and social links.
- Replace the generic GitHub project links with the exact repository URLs for each project.
- Add a resume PDF link if you'd like visitors to download your CV.
- This project is static; no backend or build step is required.


## Profile photo
Your profile photo is saved at `assets/profile.jpg` and displayed in the About section. To change it, replace that file while keeping the same filename, or update the `src` path in `index.html`.
